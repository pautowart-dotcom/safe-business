# Помощник админа студий (Telegram)

Клиенты пишут, как и раньше, в Telegram-аккаунт студии. Бот подключён к нему через
Telegram Business и отвечает от имени студии: цены, адреса, часы, ссылка на запись в Dikidi.
Всё, что требует человека (перенос, опоздание, жалоба, здоровье, голосовые, вопросы, ответа на которые нет в базе),
приходит карточкой в группу «Админ» с кнопкой «Взял».

Сценарии — [docs/studio-bot/scenarii.md](../docs/studio-bot/scenarii.md).

## Что бот делает и чего не делает

- Факты берёт только из [baza.md](baza.md). Строки с `[ЗАПОЛНИТЬ]` он не видит.
- Код дополнительно проверяет ответ ИИ: сумма в рублях или ссылка, которых нет в базе, → бот
  не отправляет это клиенту, пишет «уточню у администратора» и шлёт карточку.
- Здоровье — всегда шаблон «лучше обсудить с мастером» + карточка. Опоздание и жалоба — всегда срочная карточка.
- ИИ недоступен → «передал администратору» + карточка (клиент не остаётся без ответа).
- Админ написал в чат сам или нажал «Взял» → бот молчит в этом чате 3 часа (`pauseHoursAfterAdmin`).
- Несколько сообщений подряд — один ответ (ждёт 3 секунды).
- Переписку на диск не пишет: история в памяти, стирается через 24 часа. В `data/state.json` —
  только служебное (паузы, подключение).
- В Dikidi сам не записывает — даёт ссылку.

## Запуск

1. **Бот.** В @BotFather: `/newbot` → получить токен. Там же: Bot Settings → Business Mode → включить.
2. **Группа «Админ».** Создать группу, добавить туда бота и администратора. Написать в группе `/chatid` — бот пришлёт id.
   (Бот должен быть уже запущен — см. п. 4; сначала можно запустить без ADMIN_CHAT_ID.)
3. **Ключи.** Скопировать `.env.example` в `.env`, вписать `STUDIO_BOT_TOKEN`, `ADMIN_CHAT_ID`,
   `YANDEX_GPT_API_KEY`, `YANDEX_FOLDER_ID` (те же, что для Без.Биза, или отдельные).
4. **Старт.** `cd studio-bot && npm start`. Нужен Node 18+, установка пакетов не нужна.
5. **Проверка без Business.** Написать боту напрямую в личку — он отвечает так же, как будет отвечать клиентам.
6. **Подключить к аккаунту студии.** В Telegram на аккаунте студии: Настройки → Telegram для бизнеса →
   Чат-боты → указать бота → разрешить «отвечать на сообщения» → выбрать чаты
   (обычно «все, кроме контактов»). Нужен Telegram Premium на этом аккаунте.

## Группа «Админ»

- Карточки с кнопкой «Взял» — всё, что требует человека.
- Утром, в начале рабочего дня — сводка: сколько клиентов писало ночью, какие карточки ждут ответа
  (ссылками), сколько людей в листе ожидания. Тихая ночь — сводки нет.
- `/ozhidanie` — лист ожидания: кто хочет окно, в какой студии, на какую услугу, когда удобно.
  Бот только собирает пожелания и ничего не обещает; окно предлагает администратор сам и нажимает
  «предложили». Заявка удаляется сама через 14 дней (`waitlistDays`).
- `/probely` — чего не хватило в базе (само приходит раз в неделю).
- `/chatid` — id группы для `.env`.

## Проверка качества до клиентов

- `npm run check` — прогон 30 типовых сообщений из [test/voprosy.txt](test/voprosy.txt): смотреть, нет ли
  выдумок, кому ушла карточка, коротко ли.
- `npm run chat` — диалог в консоли (например, перенос в несколько сообщений).
- Сравнить модели: `YANDEX_GPT_MODEL=yandexgpt-lite/latest` против `yandexgpt/latest`.
- `npm test` — тесты страховок (без ключей и сети).

## Настройки — [config.json](config.json)

`workHours` и `timezone` — когда обещать «в течение часа», а когда «утром»; `replyPromise` — что
обещать в рабочее время; `answerDirectMessages` — отвечать ли тем, кто пишет самому боту.

## До запуска на реальных клиентах

- Текст про обработку сообщений помощником (YandexGPT) в политике студии — показать юристу.
- Работает, пока запущен процесс: для постоянной работы — сервер (VPS) или pm2/systemd.
