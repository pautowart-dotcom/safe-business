# Первый AI-ролик: «Сроки не должны жить в голове»

Статус: сценарий и производственный пакет для первого теста аудитории.

## Концепция

**Идея:** показать один обычный рабочий день владельца небольшой маникюрной студии. В потоке клиентов, сообщений и бытовых дел дата важного документа легко теряется. В финале не «магическое спасение», а простой порядок: список сроков, понятное следующее действие и напоминание заранее.

**Задача ролика:** вызвать узнавание и привести к бесплатной диагностике «чего вам не хватает».

**Тон:** спокойный, честный, бытовой. Без образов инспекций, штрафов, красных сирен, паники и обещаний гарантированной защиты.

**Формат:** вертикальный 9:16, 25 секунд, для Reels / Shorts / VK Клипов.

**Визуальное направление:** документальная миниатюра с мягким дневным светом в небольшой маникюрной студии; реальные рабочие детали, бумага, календарь, телефон, стерильные инструменты. Палитра: молочный, графитовый, пыльно-коралловый акцент. Чисто, но не стерильно-рекламно.

**Главный текст ролика:** «Не держите все сроки в голове».

## Раскадровка

### Кадр 1. Поток дел

- План: крупный, затем лёгкий наезд.
- Объекты: календарь без читаемых персональных данных, смартфон, закрытая папка.
- Действие: уведомление отвлекает от календаря.
- Смысл: проблема не в небрежности, а в перегруженном рабочем дне.

### Кадр 2. Срок среди бумаг

- План: серия коротких деталей, 2–3 вставки по 0,8 секунды.
- Объекты: журнал, папка, календарь, чистая рабочая зона.
- Действие: взгляд переходит от одного дела к другому.
- Смысл: документы и сроки уже существуют, но не собраны в понятный порядок.

### Кадр 3. Минута на порядок

- План: средний через плечо, затем вставка экрана.
- Действие: добавление пункта и даты в список.
- Смысл: не нужно разбираться в сложной системе; достаточно начать с нужных сроков.

### Кадр 4. Напоминание заранее

- План: крупная вставка экрана + предметный кадр журнала.
- Действие: появляется нейтральное напоминание, без красного цвета и тревожной анимации.
- Смысл: приложение помогает помнить о следующем шаге.

### Кадр 5. Возврат к работе

- План: средний, светлый, статичный.
- Действие: одно дело отмечено, владелица возвращается к клиентке.
- Смысл: порядок освобождает внимание, но не отменяет ответственность владельца.

## Промпты для генерации сцен

Общие настройки для всех сцен: вертикальное видео 9:16, 5–6 секунд на клип, realistic documentary commercial, small Russian manicure studio, natural daylight, soft handheld camera, authentic textures, restrained color grading, no logos, no readable brand names, no personal data, no watermark, no dramatic crisis, no police or inspection imagery, no red warning screens, no distorted hands, no extra fingers, no illegible gibberish text. Текст и интерфейс лучше добавить на монтаже, а не генерировать моделью.

### Финальный экран

Финальный экран не генерировать видео-моделью. Собрать в редакторе из однотонного светлого фона, названия «Безопасный бизнес» и двух строк: «Пройдите бесплатную диагностику» и «Без сбора дат на старте». Так текст будет чётким и одинаковым во всех версиях.

## Монтаж

- Темп: первые 10 секунд 3–4 коротких склейки, затем кадры чуть длиннее; ролик должен ощущаться собранным, не нервным.
- Переходы: обычная склейка, один мягкий match cut с календаря на экран списка. Не использовать вспышки, glitch и тревожные переходы.
- Субтитры: крупный гротеск, 1–2 строки, нижняя безопасная зона; не ставить текст поверх важных рук и экрана.
- Генерируемый текст в кадре заменить графикой редактора. Для интерфейса использовать вымышленную демонстрационную дату, например `через 14 дней`, без реальных данных.
- Финальный призыв держать на экране минимум 2,5 секунды.
- Сверху/снизу оставить безопасные поля под интерфейс площадки.
- Экспорт: H.264, 1080x1920, 25 или 30 fps, AAC 48 kHz, длительность 25 секунд.

## Звук

- Музыка: лёгкий instrumental lo-fi / soft marimba / brushed percussion, 85–100 BPM, без вокала и без тревожных струн.
- Громкость: музыка около -20 LUFS integrated под речевой текст не нужен; финальный мастер около -14 LUFS для соцсетей.
- Foley: уведомление телефона, лист бумаги, ручка по столу, тихие звуки студии. Каждый эффект короткий и тише музыки.
- Не использовать сирены, громкие таймеры, сердцебиение, резкие удары и звук «ошибка».
- Речь на камеру не нужна. В этом ролике всё объясняется монтажом и титрами.

## API-проверка генерации видео

### Наиболее реалистичный бесплатный путь для пробного вызова

**Hugging Face Inference Providers / HF Inference** — единственный из распространённых вариантов, который разумно рассматривать как пробный API без обязательной покупки минут. На аккаунте может быть небольшой бесплатный месячный кредит, но его размер, доступность провайдера и поддержка конкретной video-модели меняются. Требуется аккаунт и токен Hugging Face. Наличие банковской карты не следует считать гарантированным требованием для самого аккаунта, однако тарифы и лимиты нужно проверить в кабинете непосредственно перед вызовом.

Это не гарантия бесплатной генерации: у видео-моделей большой расход памяти и времени, а выбранная модель может быть недоступна через нужного inference-провайдера. По официальной документации на 23 июля 2026 года бесплатный пользовательский кредит Hugging Face составляет $0.10 в месяц и может меняться; токен всё равно обязателен. Для видеомодели может понадобиться маршрутизация через платного партнёра, поэтому перед вызовом нужно проверить фактическую цену и доступный кредит. Реалистичный результат пробного вызова — получить ошибку о недоступном провайдере, очередь или один короткий тестовый клип; строить на этом весь производственный процесс нельзя.

### Проверка Pollinations

У Pollinations есть публичный `GET /video/{prompt}` и каталог видеомоделей, но генерация требует API-ключ `pk_` или `sk_`. Анонимный запрос к короткому тестовому ролику был выполнен 23 июля 2026 года и получил `401 Unauthorized`; видео не создано. Поэтому этот сервис не подходит для запуска из текущей среды без ручной регистрации и ключа. После регистрации условия зависят от Pollen-баланса: бесплатные Pollen можно получить через доступные Quests, но это не означает гарантированно бесплатный видеовызов для каждого аккаунта.

### Что пользователь делает руками

1. Открывает Hugging Face, создаёт аккаунт и создаёт Access Token с минимальным правом, достаточным для inference.
2. Проверяет страницу конкретной text-to-video модели и вкладку Inference Providers: у модели должен быть активный провайдер, поддерживающий генерацию видео.
3. Смотрит остаток бесплатного кредита и условия оплаты. Если сервис предлагает привязать карту или включить billing, не включать это без отдельного решения.
4. Только после этого запускает локальный тест с коротким prompt и длительностью, которую допускает модель.
5. Удаляет токен из истории терминала и хранит его только в переменной окружения, не в файле проекта.

### Пример локального вызова

Ниже шаблон, а не обещание рабочего endpoint: имя модели и URL нужно взять со страницы выбранной модели в день теста.

```powershell
$env:HF_TOKEN = "hf_..."
$headers = @{ Authorization = "Bearer $env:HF_TOKEN" }
$body = @{
  inputs = "Vertical 9:16 realistic small manicure studio, calm daylight, a paper calendar and a document folder, no readable text"
} | ConvertTo-Json

Invoke-WebRequest `
  -Uri "https://router.huggingface.co/hf-inference/models/MODEL_ID" `
  -Method Post `
  -Headers $headers `
  -ContentType "application/json" `
  -Body $body `
  -OutFile ".\test-video-output.bin"
```

Проверить нужно: HTTP 200 и тип ответа. Если возвращается JSON с `error`, это не видео; если модель отвечает `loading`, повторить можно только в пределах лимитов. Не добавлять токен в сценарий, git, `.env`, который попадает в репозиторий, или скриншоты.

### Другие варианты и ограничения

| Сервис | Пробный API | Ограничение | Вывод |
|---|---|---|---|
| Replicate | Публичный API есть | Обычно нужен аккаунт, токен и оплачиваемый баланс/кредит; бесплатность конкретного вызова не гарантируется | Не считать бесплатным без проверки billing руками |
| fal.ai | Публичный API есть | Нужен ключ и кредит/аккаунт; условия меняются | Подходит для платного теста, не для обещанного free-пути |
| Runway / Kling / Luma API | API или партнёрские API доступны не всегда одинаково | Регистрация, кредиты, региональные условия и/или оплата; бесплатный публичный пробный вызов не гарантирован | Не использовать как бесплатный план по умолчанию |
| Публичные Gradio Spaces на Hugging Face | Иногда можно вызвать без отдельного API-ключа | Space может уснуть, быть закрыт, ограничить очередь или поменять API; стабильность отсутствует | Годится только для ручного одноразового эксперимента |
| Pollinations | Публичный API и видеомодели есть | Для генерации нужен `pk_`/`sk_`; анонимный тест вернул `401 Unauthorized`, расход идёт из Pollen | Нужны ручная регистрация, ключ и проверка бесплатного баланса |
| Локальный ComfyUI с video-моделью | Локальный HTTP API, без внешней оплаты | Нужна мощная видеокарта, модели занимают много места, настройка сложная | Самый независимый путь, но не самый простой для первого ролика |

Условия сервисов и доступность моделей меняются. В этом документе нет выполненного внешнего вызова и нет утверждения, что бесплатный кредит или конкретная модель доступны на дату производства.

## Следующий шаг

Сначала вручную проверить в Hugging Face одну конкретную video-модель и бесплатный остаток, не включая оплату. Параллельно собрать ролик из пяти коротких клипов или статичных изображений с лёгким движением камеры: идея и монтаж от этого не зависят. После первого теста оценить удержание на 3-й, 10-й и 22-й секунде и решить, нужен ли второй вариант с тем же сюжетом, но более коротким первым титром.
