## Как расшифровать краш через sourcemap (если всплывёт снова)

Продовый бандл (`https://lk.business-safe.ru/assets/index-XXXXX.js`) собирается с `sourcemap: true` (frontend/vite.config.js), и `.js.map` публично доступен по тому же пути (`+.map`). Рабочий метод:
```bash
curl -s https://lk.business-safe.ru/assets/index-XXXXX.js.map -o map.json
node -e "
const { SourceMapConsumer } = require('/полный/путь/к/frontend/node_modules/source-map-js');
const map = require('./map.json');
const consumer = new SourceMapConsumer(map);
console.log(consumer.originalPositionFor({ line: N, column: M })); // N:M из стека краша
"
```
Так нашли оба очага бага в этой сессии — работает надёжно, быстрее любого гадания по коду.
