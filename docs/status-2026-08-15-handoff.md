## Деплой — ничего особенного делать не нужно

Обычный процесс из `README.md` (`bash deploy/deploy.sh` на сервере после доставки кода
scp/git push) сам применит все новые миграции — `deploy.sh` уже вызывает
`node src/db/migrate.js` на каждом деплое. Отдельно накатывать миграции руками не требуется.

Новые миграции, которые применятся автоматически: `0079_hair_chemical_treatments.sql`,
`0080_expense_categories.sql`, `0081_services.sql`, `0082_working_hours.sql`,
`0083_supply_unit_cost.sql`. Все — `ADD COLUMN IF NOT EXISTS`/`CREATE TABLE IF NOT EXISTS`,
без изменения существующих данных, безопасны для накатки на прод с реальными компаниями.

Фичи-флаги не заводились — весь новый функционал живой сразу после деплоя (тот же подход,
что у изначальных 4 ниш: без отдельной "тихой обкатки").

Открыть «Финансы» → вкладку «Аналитика» и «Обзор», убедиться, что ничего не падает при
пустых данных (новые метрики рассчитаны так, чтобы честно показывать «—»/0 без данных, не
падать), и хотя бы одну новую нишу теста безопасности пройти вживую.
