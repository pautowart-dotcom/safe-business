# Упрощение Без.Биз — план 09.11.2026

Зачем: даже владельцу сложно заходить в приложение. Идеи/код больше не дефицит; дефицит — понятный вход и разовые деньги без дорогого ИИ на бесплатных.

Связь: продолжает шаг 2.5 из `docs/plan-2026-10-26.md` («понятность»). Меняет ставку «сила = подписка» на **бесплатный план шагов + разовый артефакт**. Релокант и прочие проекты — фон, не этот спринт.

---

## 1) Идеал для человека (одна петля)

```text
Тест / ветка вопросов (бесплатно, без ИИ)
  → «Что сделать» — 1–3 следующих шага (бесплатно)
    → Разово: журналы / шаблоны / юрист-партнёр (деньги)
      → По желанию: даты в «Мои сроки» (бесплатно, не обязательно)
```

Не обещаем «защитим от штрафов». Обещаем: **понятный порядок и готовые бумаги**.

---

## 2) Правило ИИ (чтобы не уйти в минус)

| Слой | ИИ |
|---|---|
| Бесплатный путь (тест → шаги → инструкции) | **Нет.** Правила + готовый контент, как сейчас |
| Разовый разбор / редкие сценарии | Позже, только после оплаты или лимита |
| Чат «спроси что угодно» на главной | Не в бесплатном MVP упрощения |

Вчерашний разговор (НПД → патент → касса) — образец **ветки на правилах**, не повод включать модель на каждый клик.

---

## 3) Что упростить в кабинете (смысл, не косметика)

Сейчас владелец видит слишком много миров сразу: безопасность + финансы + склад/визиты через «Ещё» + подписка + онбординг-простыня.

**Цель упрощения:** зайти → за 10 секунд понять *один* следующий шаг.

### Главная (владелец)

Оставить только:
1. Короткий статус («осталось N шагов» / «на этой неделе»).
2. **Один** следующий шаг с кнопкой.
3. Блок «Готовые бумаги» (журналы/шаблоны) — разовая оплата.
4. Мелкая ссылка: сроки, финансы, остальное.

Убрать с первого экрана: простыни метрик, онбординг из многих слайдов, давление «оформи подписку», виджеты без действия.

Опора: уже есть `HomePath.jsx` и вкладка «Шаги» — усилить их, не строить третий центр.

### Меню владельца

**Финансы не трогаем** (09.11, владелец): у чужих студий модуля часто нет, у своих — ок как есть. Не тратим спринт на перестановку таббара.

Фокус упрощения — **внутри Главной и Безопасности**, не в нижней навигации:

| Сейчас | Решение |
|---|---|
| Главная перегружена | Статус + **один** следующий шаг + вход в бумаги |
| «Безопасность» = много вкладок сразу | По умолчанию **Шаги**; тест/документы/сроки/проверка — вторично |
| Подписка в центре внимания | Приглушить; на видное место — **разовый пакет журналов** (шаблоны рядом, если уже есть покупка) |

### Внутри «Безопасности»

Не удалять модули сразу. **Спрятать глубину:**
- По умолчанию: Шаги.
- Вторично (аккордеон/«Ещё в разделе»): тест, документы, мои сроки, если проверка, снаружи.
- Новичку не показывать все вкладки сразу.

## 4) Деньги без подписки (оффер)

| | Что | Цена (решение позже) |
|---|---|---|
| Бесплатно | Тест + план шагов + инструкции | 0 |
| Разово A | Пакет нужных журналов PDF | одна покупка |
| Разово B | Пакет шаблонов (оферта, согласия…) | уже заложено в онбординге |
| Разово C | «Разобрать мой случай» / партнёр (НПД→патент и т.п.) | человек или партнёр |

Подписку не рекламировать как must. Кабинет может оставаться бесплатным. Повторные деньги — новый пакет / партнёр при смене правил, не абонплата «за воздух».

---

## 5) Что сознательно не делаем в этом плане

- Не переписываем весь frontend и не трогаем Релокант/Masaway.
- Не добавляем вопросы в диагностический тест без отдельного решения (правило 28.10).
- Не включаем платный ИИ на бесплатный поток.
- Не строим «систему всего бизнеса РФ» — только понятный путь студии + разовые бумаги.
- Не App Store и не «взрыв».

## 7) Критерий «стало проще»

- Ты сам заходишь без раздражения и сразу видишь, что нажать.
- Новый человек за 1 минуту понимает следующий шаг.
- Бесплатный путь не жжёт бюджет модели.
- Есть ясное разовое «купить бумаги», не «оформи подписку».

---

## Решение владельца (зафиксировано 09.11.2026)

Владелец: «нужен продукт которым пользуются, который помогает и даёт денег»; по деталям UI «не знаю как лучше» — решает агент. Финансы не трогаем.

| Вопрос | Решение |
|---|---|
| Порядок A → B → C | **Да** |
| Финансы / таббар | **Не трогаем** |
| Подписка vs разово | **Приглушить подписку**, деньги с **разового пакета журналов** (+ шаблоны если уже в продукте) |
| Первая полка | **Журналы** (главный артефакт помощи); шаблоны — второй кнопкой, не вместо |
| Критерий недели | Человек зашёл → видит следующий шаг → может купить/скачать пакет без обязательной подписки |

Дальше без новых опросов: этап **A** (карта путаницы Главная + Безопасность), затем B и C.
