### `199dcfc` — ниша визита, Финансы по нише, честный интерфейс, лендинг v2
Реальный повод: у владельца двое знакомых с массажными студиями,
интерфейс был явно заточен под маникюр.
- **Ниша визита** (миграция `0066`) — опциональное поле в форме визита,
  показывается только если у компании выбрано больше одной ниши;
  валидируется на бэкенде по факту выбранных ниш компании (не по
  фиксированному списку). Ниши компании теперь отдаются в
  `GET /platform/companies/current` (это не owner-only роут, в отличие
  от всего `/modules/security/*`, а форма визита нужна и мастеру/админу).
- **Финансы → "Выручка по нише"** — новая карточка, видна всем ролям
  (как разбивка по мастерам, не как способ оплаты), считается через
  `finance_entries JOIN visits`, показывается только когда есть визиты
  с указанной нишей.
- **Честность интерфейса**: экран входа ("Платформа для студий
  маникюра" → "...красоты и здоровья"), плейсхолдеры в
  Визитах/Складе/Клиентах (были все "Маникюр + гель-лак").
- **Иконка фото в визите** — было два отдельных input'а (камера отдельно,
  галерея отдельно) с двумя иконками, теперь один input без `capture`,
  системный диалог выбора источника.
- **Лендинг, версия 2** — по запросу "посовременнее", выбрали "жирный
  SaaS-стиль" (см. вопрос владельцу с превью 3 вариантов). Первая версия
  (тема "бумага и печать") в git не попала — её переписали раньше, чем
  закоммитили.

  отдельный nginx location `/api/platform/support/` с
  `client_max_body_size 25M`, общий лимit сервера остался 8M). Видно и
  клиенту, и в админке.
