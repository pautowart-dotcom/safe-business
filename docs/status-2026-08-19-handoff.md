## ⚠️ Не работает прямо сейчас — заблокировано, не трогать до дальнейшего решения владельца

**ИИ-ассистент отвечает 401 `Unknown api key` при попытке написать в чат.** Причина, по разведке
через WebSearch (официальные страницы документации отдали капчу, точный ответ НЕ подтверждён
первоисточником): эндпоинт function calling (`ai.api.cloud.yandex.net/v1/chat/completions`,
"Yandex AI Studio") похоже требует **отдельный ключ**, не тот статический ключ сервисного аккаунта,
что уже работает для текстовых советников (`yandexAssist.js`, другой эндпоинт —
`llm.api.cloud.yandex.net/foundationModels`). По документации, ключ для AI Studio создаётся в самом
интерфейсе `aistudio.yandex.ru` (в правом верхнем углу), выдаётся как пара ID+секрет, а не один
статический ключ.

**Владелец должен зайти на aistudio.yandex.ru и посмотреть, что там реально предлагается создать —
это следующий шаг, отложен на 2+ часа (владелец уезжает).** Не гадать код заново без реального
скриншота интерфейса — предыдущие две попытки (endpoint URL, заголовки) не подтвердились сразу.

Советники на `/ai-advisor` (текст через yandexAssist.js) этой проблемой не затронуты — они бьют в
другой эндпоинт с уже рабочим ключом (не проверено вживую с реальным ответом ИИ на момент хендоффа,
но архитектурно не должны упасть так же).
