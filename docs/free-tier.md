# Бесплатный уровень и одна воронка

18.10.2026, решение владельца («да, поехали, надо пробовать»). Код: `backend/src/core/freeTier.js`.

## Правило

**Бесплатно — знать. Платно — не думать.** Заключение бесплатно не отдаём.

| | Бесплатно | Подписка (1990 ₽/мес) |
|---|---|---|
| Тест, индекс, список нарушений (только названия и риск) | да | да |
| Заключение: штраф, норма, что делать, PDF | — | да |
| «Мои сроки», главная «Что сделать», «Готово», «Напомнить позже» | да | да |
| Напоминание в день срока | да | да |
| Напоминания заранее (за 30, 14, 7 дней) | — | да |
| Проверка месяца, ИИ-советник, дата с фото документа | — | да |
| Разовые покупки (документы, проверка сайта, план открытия) | отдельно | отдельно |

Одна воронка: тест без регистрации → «сохранить результат» (почта, пароль) → пробный месяц со всем → дальше бесплатный уровень, подписка предлагается на своём сроке (шторка срока) и на закрытых разделах (шторка «Это входит в подписку»).

## Что поменялось в коде

- После пробного месяца или окончания подписки кабинет не закрывается целиком: открыто бесплатное, платные разделы отвечают `402 paidFeature` — приложение показывает шторку, а не уводит на страницу оплаты.
- Напоминания заранее (`scripts/deadlineReminders.js`) — только при подписке или в пробный месяц; в день срока — всем.
- Проверка месяца не предлагается бесплатному уровню.
- Пробный месяц гостя считается с момента «сохранить результат», а не с начала теста.
- Заключение (штраф, норма, решение) не уходит с сервера без права на него — и в `/status`, и в `/violations`. Раньше `/violations` отдавал его гостю без оплаты.
- Тексты главной сайта больше не обещают «суммы штрафов» в бесплатном тесте.

## Включение

- По умолчанию — только тестовые компании (`companies.is_test`).
- Для всех: `FREE_TIER_ENABLED=true` в `backend/.env` и перезапуск. Выключить — убрать строку.
- 19.10.2026 владелец решил включить без юриста («много правок, по каждой к юристу дорого»). Оферта: п. 3.6.1 «Мои сроки» по подписке — с напоминаниями заранее, новый п. 3.9 «Бесплатный доступ» (миграция `0144_oferta_free_tier.sql`). Текст не юриста, сверен с `freeTier.js`; показать юристу при следующем обращении.
