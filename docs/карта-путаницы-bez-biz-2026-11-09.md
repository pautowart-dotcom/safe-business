## Главная (`/`)

| Блок | Зачем человеку | Вердикт |
|---|---|---|
| HomeHero (индекс / «Нужно внимание: N») | Статус | **Оставить**, но N не раздувать сроками+шагами до ощущения «41 дело» |
| «С чего начать» (`FirstSteps`) | Онбординг без слайдов | **Оставить** (уже лучше длинного Onboarding) |
| HomeQuick (сетка кнопок) | Быстрые разделы | **Спрятать или 2 кнопки**: «Следующий шаг», «Бумаги/шаблоны». Сейчас конкурирует с «Что сделать» |
| «Что сделать» + NextStepRow | Центр действий | **Оставить ядром**. NextStep — сверху. Сроки без даты / шум — ужать (лимит уже есть `ACTIONS_CENTER_VISIBLE`) |
| «Что мы проверили» + теги «По подписке» | Лента законов | **Убрать с первого экрана** или свернуть в «Ещё / новости». Давит подпиской без помощи «что сделать» |
| Баннеры Install / Push / Opening / Network | Инфра | Оставить только если реально нужны; не выше NextStep |
| StatRow (десктоп: выручка, отчёты…) | Операционка | Не трогаем для чужих (финансов часто нет); у своих не на первом смысловом месте пути |

**Путаница:** на одном экране смешаны «путь безопасности», дедлайны, лента законов и быстрые кнопки → даже знающему человеку шумно.

## Безопасность (`/security`, SecurityPath)

Уже правильная идея: Узнать → Исправить → Держать → Быть готовым + одна кнопка «что дальше».

| Что | Вердикт |
|---|---|
| 4 этапа + Ring | **Оставить** каркас |
| Этап 2 «Исправить» / шаги | **Главный экран по умолчанию** после теста (сейчас `current` так и считает — ок) |
| Ссылка «Шаблоны документов ↓» | **Поднять**: это разовые деньги и помощь. Сделать карточку «Скачать шаблоны» рядом с следующим шагом, не только якорь вниз |
| PDF-отчёт «по подписке» | **Переформулировать** под разовую оплату или «в пакете», не «оформи подписку» (согласовано 09.11) |
| Мои сроки / проверка месяца / снаружи | **Вторично** — внутри этапов 3–4, не конкурировать с шагом 2 на главной |
| Старый SecurityDashboard | Не удалять — откат флагом |

**Путаница:** шаблоны и журналы не ощущаются «полкой товаров»; подписка всё ещё язык paywall.

## Предложение к этапу B (ещё не код — утвердить)

Минимальный обратимый дифф (флаги + ветка):

1. **Главная владельца:** порядок блоков = FirstSteps (если нужно) → NextStep → карточка «Бумаги: шаблоны» → ужатое «Что сделать» (сроки). HomeQuick свернуть до 0–2. Ленту «Что мы проверили» спрятать за «Показать новости закона».
