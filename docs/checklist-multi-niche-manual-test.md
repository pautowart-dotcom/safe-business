# Чек-лист: мультивыбор ниш ("Красота и здоровье")

Проверка вручную в приложении. Не нужно ничего знать про код — просто пройти
шаги и сверить с ожидаемым результатом. Если что-то не совпало — просто
опишите, на каком шаге и что увидели (скриншот приветствуется).

## 1. Выбор нескольких ниш при регистрации новой студии

1. Зарегистрировать новую тестовую студию (или использовать уже созданную
   тестовую).
2. На экране "Определим сферу деятельности" выбрать сферу **"Красота и
   здоровье"**.
3. В поле "Ниши" отметить сразу две-три ниши, например Маникюр + Ресницы и
   брови + Волосы.

**Ожидается:**
- Выбранные ниши подсвечиваются, можно отметить сразу несколько (не только
  одну).
- Повторный клик по нише снимает выделение.
- Кнопка "Продолжить" неактивна, пока не выбрана хотя бы одна ниша.
- После нажатия "Продолжить" — переход дальше без ошибок.

## 2. Прохождение теста безопасности по нескольким нишам подряд

1. В той же студии пройти тест безопасности сначала по одной из выбранных
   ниш, потом (не выходя из приложения) — по второй.

**Ожидается:**
- Обе сессии теста проходят без сбоев.
- После прохождения обеих — в общем разделе безопасности виден один общий
  индекс/статус, учитывающий обе ниши (а не только последнюю пройденную).

## 3. Добавление ниши позже

1. В студии, где уже есть история пройденных тестов, зайти в настройки
   сферы деятельности и добавить ещё одну нишу (например Массаж).

**Ожидается:**
- Ничего из старой истории (пройденные тесты, найденные нарушения) не
  пропало и по-прежнему видно.
- Новая ниша появилась в списке актуальных ниш.

## 4. Удаление ниши позже

1. В той же студии убрать одну из ранее выбранных ниш.

**Ожидается:**
- Старая история по убранной нише остаётся видна (не удаляется), просто
  эта ниша больше не входит в текущий список и не влияет на новый расчёт
  индекса.
- Список актуальных ниш в интерфейсе обновился и больше не показывает
  убранную нишу как активную.

## 5. PDF и справочник документов при нескольких нишах

1. Открыть вкладку "Документы" у студии с несколькими нишами — свериться,
   что нужные разделы есть.
2. Скачать PDF-журнал.

**Ожидается:**
- Разделы, которые по смыслу одинаковые для разных ниш (например
  инструктаж), показаны **один раз**, а не задвоены как две одинаковые
  секции подряд.
- PDF открывается, читаем, ничего не обрезано и не съехало.

---

**Что уже проверено по коду и трогать не нужно** (независимо подтверждено
разбором самого приложения, не требует повторной проверки руками):
- Перенос данных у студий, у которых была только одна старая ниша (до
  введения мультивыбора) — происходит автоматически при обновлении, без
  ручных шагов и без риска потери истории.
- Удаление ниши на уровне базы данных не может стереть исторические сессии
  или нарушения — они привязаны к студии, а не к самой нише.
