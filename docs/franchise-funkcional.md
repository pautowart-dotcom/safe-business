## 1. Главная логика в одном абзаце

У одной точки событий мало, у сети из 150 точек — каждую неделю. Продукт превращает каждое событие точки (новый сотрудник, истёк документ, пришла проверка, поменялся закон, открывается новая точка) в **задачу для точки** и в **строку в пульте франчайзера**. Точка получает «что сделать до пятницы», франчайзер — «где в сети горит», юрист — заявки там, где точка сама не справится. Деньги: сеть платит за пульт и порядок во всей сети, юрист — дополнительный доход.

Три правила, без которых всё развалится:
1. **Ввод в одно действие.** Точки не заполняют формы (урок «Моих сроков»: 0%). Фото медкнижки или предписания → система сама достаёт дату и тип.
2. **Франчайзер видит статусы, а не людей.** «В точке Казань-2 истекают 2 медкнижки», без ФИО: персональные данные сотрудников — у точки (152-ФЗ).
3. **Франчайзеру не нужно заходить в систему.** Ему раз в месяц приходит отчёт по сети; пульт — для тех, кто хочет глубже.

## 6. Связи — главные цепочки

1. **Новый сотрудник** → Ф17 задачи (медкнижка, инструктаж, согласие, договор) → Ф19 сроки → напоминания Ф24 → пульт Ф27 «без медкнижки: N точек» → если точка не справляется — юрист Ф23 (кадровые документы).
2. **Проверка у точки** → Ф22 разбор бумаги → план ответа → юрист Ф23 (платно) → радар Ф30 обезличенно → задача всем точкам «проверьте X» → отчёт Ф28 «проверок за месяц: 3, все закрыты».
3. **Изменился закон** → Ф32 карточка «как касается» → задача точкам нужной ниши → % выполнивших в пульте → нужен новый документ → шаблон Ф20 или юрист Ф23.
4. **Новая точка** → Ф8 роадмап → Ф29 воронка у франчайзера → Ф9 «Открылись» → Ф14 тест → в пульте.
5. **Точка тонет** (красная зона / не заходит) → Ф33 сигнал → франчайзер звонит → юрист или самопроверка.
6. **ЧП** → Ф12 порядок действий → сигнал франчайзеру сразу → юрист.

Деньги в цепочках: подписка (точка или сеть), юрист (% с каждой заявки), шаблоны, роадмап для новых точек.

Принцип для всех этапов (владелец 16.10): «не везде серьёзная компания» — максимально вовлечены в бизнес человека, живой тон, реакция на каждое действие, без обещаний результата.
