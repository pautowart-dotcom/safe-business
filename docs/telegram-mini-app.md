# Кабинет в Telegram — как включить

Код готов (18.10.2026). Кабинет — тот же, что на сайте, открывается кнопкой в боте. Первый раз человек входит обычно (почта, пароль, код), дальше Telegram открывает кабинет сразу.

## Что сделать владельцу (один раз, ~10 минут)

1. **Выложить код** — обычный `deploy/deploy.sh`. Он применит миграцию `0141_telegram_links.sql` и новую настройку nginx (разрешение открывать кабинет внутри web.telegram.org).
2. **Создать бота** в Telegram: написать `@BotFather` → `/newbot` → название (например, «Безопасный бизнес») → имя бота на латинице, оканчивается на `bot`.
3. BotFather пришлёт **токен** вида `1234567:AA…`. Никуда его не пересылать и в файлы проекта не класть.
4. На сервере в `backend/.env` добавить строку `TELEGRAM_BOT_TOKEN=<токен>` и перезапустить бэкенд: проще всего ещё раз `deploy/deploy.sh` (он делает `pm2 startOrReload deploy/ecosystem.config.js`).
5. В `@BotFather` → `/mybots` → ваш бот → **Bot Settings → Menu Button** → указать адрес `https://business-safe.ru/lk/` и текст кнопки «Открыть кабинет».
6. Там же можно задать описание и картинку бота (`/setdescription`, `/setuserpic`).

## Как проверить

- Открыть бота с телефона → кнопка «Открыть кабинет» → войти почтой и паролем → вверху появится «Telegram привязан — дальше без пароля».
- Закрыть и открыть снова — кабинет откроется сразу, без входа.
- В «Настройках» видно «Вход через Telegram: привязан @ник» и кнопку «Отвязать».

## Что внутри (для справки)

- Подпись Telegram проверяется на сервере токеном бота; данные старше суток не принимаются.
- Храним только числовой id Telegram и ник — без телефона и имени из Telegram.
- Вход без пароля — только для Telegram, который человек сам привязал после полного входа. Супер-админ через Telegram не входит.
- В Telegram скрыты баннеры «установите приложение» и «уведомления на iPhone», стрелка «назад» — системная кнопка Telegram.
