# Шаблоны документов по персональным данным от юриста — инструкция

19.10.2026, первая часть шаблонов (документы по ПД). Папка юриста: Google Drive (ссылка у владельца). Оферты по видам услуг юрист пришлёт позже — «посложнее будет».

Инструкция записана с голосового сообщения юриста (через владельца), по смыслу, без додумывания.

## 1. Политика обработки персональных данных

- Указать ссылки на сайт.
- Указать сведения об операторе.
- **Раздел 2** — цели. Указываются цели, связанные с обработкой данных на сайте, по виду деятельности. Пример: салон → «оказание косметических услуг».
- **Раздел 5, пункт 5.8** — если на сайте нет Яндекс Метрики, пункт удаляется.
- **Приложение** — юрист подписал самые популярные цели как образец:
  - если какой-то обработки на сайте нет — цель убираем;
  - если есть своя — дополняем (пример: «демонстрация работников» — отдельная цель);
  - для каждой цели: объём данных и способ обработки — по образцу.

## 2. Согласие на использование изображения

- Указать сведения об операторе.
- **Второй абзац** — обязательно указать, на каком основании: по бартеру или безвозмездно. При необходимости поменять формулировку.

## 3. Согласие на обработку ПД на бумаге

Если данные обрабатываются на бумаге, а не на сайте — заполняется от руки:
- ФИО субъекта;
- сведения об операторе;
- цель (пример: запись на услуги, если запись ведётся вручную, не на сайте);
- перечень данных — у юриста в образце: фамилия, имя, контактный номер телефона. Указывать фактический перечень.

## 4. Согласие на обработку ПД на сайте

Своя специфика по форме: указывается объём данных, цель и сайт, на котором ведётся обработка.

## 5. Согласие на распространение ПД

- Сведения об операторе.
- Цель — пример: демонстрация отзывов, если отзывы не обезличены.
- Данные — например: фамилия, имя, фото- и видеоизображение.
- **Фото и видео — не биометрия и не специальная категория**: биометрия — это данные для установления личности (например, отпечаток пальца). Обычное фото или видео — нет.

## 6. Согласие на рекламную рассылку

Указать сведения об операторе. Остальное — стандартные формулировки, можно использовать и размещать на сайте как есть.

## Что делаем с шаблонами (план)

- [ ] Владелец скачивает файлы из папки в `docs/legal-templates-2026-10/`.
- [ ] Сверить с нашими документами (политика, согласия: личный кабинет, заказ, обратная связь) — что уже совпадает, что добавить (изображение, распространение, рассылка, бумажное).
- [ ] Шаблоны для клиентов (студий) — как документы, которые сервис помогает заполнить под свою студию.
