### iOS-баги (найдены при живом тестировании на телефоне)
- **Pull-to-refresh не работал в установленной на "Домой" версии** (standalone). Найдено и
  почищено по шагам: (1) `html`/`body` без фиксированной высоты — страница скроллилась сама
  по себе поверх внутреннего контейнера, из-за этого сдвигалась вся "прилипшая" шапка; (2)
  React вешает `onTouchMove` как пассивный обработчик по умолчанию — `preventDefault()` внутри
  него браузер тихо игнорирует, поэтому нативная резинка контейнера всегда побеждала жест;
  touchmove переехал на обычный `addEventListener(passive:false)`.
- **Поле `<input type="date">` вылезало за карточку** на iOS, пока пустое (известный баг
  WebKit) — общее CSS-правило с `!important` на все даты в приложении разом.

**Оба фикса НЕ подтверждены владельцем на реальном устройстве** — техническая гипотеза с
конкретной устранённой причиной, не наугад, но первое подтверждение ещё не пришло. Если после
деплоя всё ещё не работает — разбираться дальше здесь.

## Открытая тема для нового чата — боевой режим ЮKassa

Код полностью готов и идентичен для теста/боя — переключение только через `.env`
(`YOOKASSA_SHOP_ID`/`YOOKASSA_SECRET_KEY`, тестовые начинаются с `test_`, боевые — с `live_`).
Крон ежемесячного автосписания (`chargeRecurringSubscriptions.js`) уже стоит на сервере
(`15 4 * * *`), проверено в этой сессии.

**Единственный блокер — не технический, а организационный.** Владелец уже писал в поддержку
ЮKassa: у него есть аккаунт (заводил магазин под телеграм-бота), но **под каждый проект нужен
свой отдельный ShopID** — ответ поддержки подтвердил, использовать тот же магазин для
"Безопасный бизнес" нельзя. Дальше по их же инструкции:
1. В личном кабинете ЮKassa → блок с названием магазина → "Добавить магазин".
2. Заполнить заявку: если платежи принимаются на сайте — вариант "На сайте" + указать
   `business-safe.ru`.
3. Магазин проверяют менеджеры не сразу, подать вторую заявку, пока первая не рассмотрена,
   нельзя.

**Что делать в новом чате:** уточнить у владельца, подал ли он уже заявку и что ответили. Как
только появятся боевые `live_` ключи — просто вписать в `.env` на сервере и перезапустить
backend (`pm2 restart safe-business-api`), плюс один раз указать боевой webhook-URL в личном
кабинете ЮKassa (`https://business-safe.ru/api/platform/subscription/webhook` — про смену
поддомена на путь уже учтено, см. комментарий в `subscription.routes.js`).
