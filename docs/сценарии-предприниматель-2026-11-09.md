# Сценарии для предпринимателя — каталог веток (09.11.2026)

**Зачем:** чтобы зайти в продукт было **легче, чем писать в ChatGPT**. Человек выбирает ситуацию → отвечает на 5–8 коротких вопросов → получает **свой** порядок шагов. Без платного ИИ на бесплатном пути.

**Статус:** черновик продукта/контента. Шаги — по живому разбору владельца и типичным кейсам студий. Перед продажей/публичным обещанием — сверка law-compliance-monitor / первоисточники (налоги, касса, ПДн).

**Связь:** [`упрощение-bez-biz-2026-11-09.md`](упрощение-bez-biz-2026-11-09.md), тест безопасности остаётся отдельным входом (вопросы в тест не добавляем без решения владельца). Эти ветки — **второй вход**: «Разбор ситуации» / «Что оформить».

---

## Как человек находит нужное

Один экран-каталог (будущий UI), не 40 разделов:

| Хочу… | Ветка |
|---|---|
| Принимать оплату картой / завести кассу | S1, S2 |
| Сменить налог / статус | S1, S3 |
| Открыть или привести студию в порядок к проверке | S4, тест безопасности |
| Нанять первого человека | S5 |
| Сайт / бот / реклама и персональные данные | S6 |
| Срок патента / взносы / ЭЦП | S7 + «Мои сроки» |

В каталоге — **название человеческим языком**, не коды законов.

---

## Общий контракт ветки

```text
Вход (1 экран) → 5–8 ответов → план: 3–12 шагов по порядку
  → у каждого шага: что сделать / куда / что подготовить
  → платно рядом (не обязательно): шаблон / партнёр / «проверит человек»
```

Поля шага: `title`, `why`, `how` (коротко), `paid` (null | templates | partner | consult), `confidence` (ok | check | gap).

---

## S1 — НПД → патент + касса (карта / терминал)

**Откуда:** живой диалог 08–09.11.2026 (самозанятая хочет патент и оплату картой).

### Вопросы

1. Сейчас: только НПД / уже есть ИП / не знаю  
2. Зачем переход: карта и касса / лимит НПД / найм / другое  
3. ЭЦП есть? да / нет / не знаю  
4. Банк для бизнеса уже есть? да / нет  
5. Ниша (маникюр / брови / другое из списка)  
6. Регион (хотя бы субъект РФ) — для патента  
7. Будут ли сотрудники сразу? нет / да  

### Черновик шагов (порядок; детали и нормы — на проверку)

1. Понять, нужен ли **ИП** (патент — у ИП; самозанятость НПД — другой режим).  
2. **Сняться с НПД** в приложении «Мой налог» (если уходит с самозанятости).  
3. Зарегистрировать ИП (если ещё нет) — через Госуслуги / ФНС / МФЦ.  
4. **Заявление на патент** — с ЭЦП через Госуслуги/ЛК ФНС или бумажно.  
5. Дождаться патента; зафиксировать даты начала/конца → потом сроки оплаты в «Мои сроки».  
6. Расчётный счёт / договор с банком на эквайринг; уточнить, что банк даёт по терминалу.  
7. **Онлайн-касса / фискальный накопитель** — что входит в «бесплатный терминал» банка, а что оплачивается отдельно (ФН, ОФД, подписка).  
8. Настроить кассу: чеки уходят в режиме **патента**, не УСН «по ошибке».  
9. Проверочная продажа → чек → сверка в ЛК ОФД / кабинете.  
10. Если ниша с помещением — параллельно не забыть санитарный минимум (тест Без.Биз / журналы).

### Платно рядом

- Пакет шаблонов (если нужны договоры/согласия при приёме).  
- Партнёр: ЭЦП, касса/ОФД, бухгалтер на подачу патента.  
- «Разобрать мой случай» — человек, не модель.

### Пометки confidence

Большинство шагов — `check` до сверки с актуальной инструкцией ФНС/54-ФЗ по кассе. Не обещать «оформим за вас» без партнёра.

## S2 — Уже ИП на патенте, нужна касса / карта

### Вопросы

1. Патент уже есть? да / оформляю / нет  
2. Терминал/касса: ничего / только эквайринг банка / касса есть  
3. Чеки уходят? да / не знаю / нет  

### Шаги (черновик)

1. Проверить вид деятельности в патенте vs фактические услуги.  
2. Выбрать схему: аренда/покупка кассы + ФН + ОФД.  
3. Регистрация кассы в ФНС.  
4. Привязка к патенту / правильный тег налогообложения в кассе.  
5. Тестовый чек + контроль в ОФД.  
6. Срок замены ФН — в «Мои сроки».

Платно: партнёр по кассе; шаблоны — по желанию.

---

## S3 — Открыть ИП с нуля под студию красоты

### Вопросы

1. Уже самозанятый?  
2. Один или с мастерами?  
3. Помещение / на выезде / дома?  
4. Режим: патент / УСН / не знаю  

### Шаги (черновик)

1. Выбрать режим (короткая памятка + «нужна консультация»).  
2. Регистрация ИП.  
3. Патент или уведомление УСН — в срок.  
4. Счёт, касса при необходимости.  
5. Бесплатный **тест безопасности** Без.Биз по нише.  
6. Пакет журналов/шаблонов — разовая полка.

---

## S4 — «Боюсь проверки» / навести порядок в студии

Это не отдельный налог, а **мост в уже существующий продукт**:

1. Пройти тест.  
2. Следующий шаг до 100 %.  
3. Разово: журналы / шаблоны.  
4. По желанию: сроки, проверка месяца.

Каталог ведёт сюда формулировкой: «Подготовиться к проверке / понять, чего не хватает».

---

## S5 — Первый сотрудник / мастер в точке

### Вопросы

1. Как оформляете: ТД / ГПХ / самозанятый арендатор места / не знаю  
2. Есть ли уже медкнижки, инструктажи  

### Шаги (черновик)

1. Выбрать модель сотрудничества (с пометкой «нужна проверка»).  
2. Договор / согласие на ПДн / правила студии — шаблоны.  
3. Медкнижка, инструктажи — в шаги теста/документы.  
4. Сроки по сотруднику — «Мои сроки».

---

## S6 — Сайт, бот, реклама и персональные данные

### Вопросы

1. Есть сайт / бот записи / только соцсети  
2. Собираете телефоны/имена клиентов?  

### Шаги (черновик)

1. Политика / согласия — пакет шаблонов.  
2. Уведомление Роскомнадзора — check / партнёр.  
3. Если ИИ-бот — блок из плана 28.10 (без новых вопросов в тесте).  
4. Текст для бота «вы общаетесь с ИИ» — из пакета.

---

## S7 — «Когда платить патент / взносы / продлить ЭЦП»

Не длинный квиз: сразу в **Мои сроки** + короткая памятка.

1. Внести даты патента / ЭЦП.  
2. Система считает напоминания (патент — уже в коде, см. plan-2026-10-26).  
3. Если дат нет — 3 вопроса и подсказка «откуда взять дату».

---

## Как это станет легче чата

| Чат с ИИ | Ветка в продукте |
|---|---|
| Каждый раз объяснять ситуацию | Ответы сохраняются в кейсе студии |
| Риск устаревшего совета | Шаги с `ok/check/gap` и датой сверки |
| Нет «сделать» | Кнопка: шаблон / партнёр / отметить сделанным |
| Дорого на всех бесплатных | Правила + контент, ИИ не в цикле |

Критерий: владелец в ситуации S1 открывает каталог веток **раньше**, чем Telegram с ассистентом.

---

## Порядок внедрения (после домашнего теста simpleHome)

1. Только **S1** как кликабельный прототип (даже статичная страница/markdown в кабинете).  
2. S4 = уже существующий путь (тест) — просто ярлык в каталоге.  
3. S2, S3 — добор.  
4. S5–S7 — когда S1 даёт касания.  
5. Код движка веток — не раньше, чем тексты S1 сверены и simpleHome принят.

---

## Не делать

- Не обещать оформление патента/кассы «под ключ» без партнёра.  
- Не кормить бесплатный каталог платным LLM.  
- Не смешивать с Релокантом в одном спринте.
