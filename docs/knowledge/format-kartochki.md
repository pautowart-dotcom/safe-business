# Формат карточки знаний (А1)

Черновик 13.10.2026. Где хранить карточки (файлы или база) — следующий пункт, А2. Здесь только **что** в карточке.

Одна карточка = один вопрос, как его задаёт владелец. Из карточки потом работают ИИ, статьи сайта, тест, «Центр действий» и проверка свежести законов.

## Поля

| Поле | Что это | Обязательно | Кто пользуется |
|---|---|---|---|
| `id` | Короткий код: `KN-кадры-001` | да | все |
| `тема` | Одна из: регистрация и статус, касса и чеки, налоги, сотрудники, помещение, санитария, клиенты, банк, проверки | да | сайт, поиск ИИ |
| `вопрос` | Словами владельца, не юриста: «Нужна ли медкнижка мастеру?» | да | ИИ, сайт |
| `как_ещё_спрашивают` | 3–5 других формулировок и сленг («санкнижка», «медуха») | да | поиск ИИ |
| `короткий_ответ` | 1–3 предложения. Если ответ «зависит» — так и пишем, и от чего | да | ИИ, сайт, «Центр действий» |
| `от_чего_зависит` | Условия: регион, режим (НПД / патент / УСН / ООО), ниша, есть ли сотрудники, вид работ. Для каждого условия — свой ответ | если ответ разный | ИИ (подставляет данные компании) |
| `шаги` | Что сделать по порядку | если есть действие | ИИ, «Центр действий», статья |
| `частые_ошибки` | Что путают и почему говорят по-разному | желательно | ИИ, статья |
| `что_будет_если_нет` | Штраф со статьёй и разбивкой ИП / юрлицо, или «прямого штрафа нет» | если есть | тест, статья |
| `первоисточники` | Номер документа + пункт + ссылка. Только то, что открыли сами. В коде (с 19.10.2026) — `{ norm: '<ключ>', points: 'п. …' }`, норма из реестра `backend/src/modules/knowledge-cards/norms.js`; строкой — только разовый документ (письмо, разъяснение). Новая норма — сначала в реестр. Что на какой норме стоит: `node src/scripts/normsReport.js` | да | проверка свежести, юрист |
| `не_сверено` | Что взяли из вторичных источников или не смогли открыть | если есть | юрист, ИИ (говорит «уточните») |
| `проверено` | Дата последней сверки с первоисточником | да | law-compliance-monitor |
| `статус` | `черновик` / `проверено по первоисточнику` / `проверено юристом` / `устарело` | да | ИИ решает, насколько уверенно отвечать |
| `связано` | Коды пунктов теста (`MA-…`) и других карточек | желательно | тест, сайт (ссылки) |

Поля нарочно совпадают по смыслу с пунктами теста (`description` ≈ `короткий_ответ`, `howTo` ≈ `шаги`, `fineText` ≈ `что_будет_если_нет`, `normBase` ≈ `первоисточники` + `не_сверено`) — так карточку и пункт теста можно искать одним и тем же поиском ИИ.

**Правило для ИИ по статусу:** `черновик` и `устарело` — ИИ не цитирует как факт, говорит «по этому вопросу у меня нет проверенного ответа». Поле `не_сверено` ИИ пересказывает честно: «это место лучше уточнить у юриста».

## Пример: «Нужна ли медкнижка мастеру?»

Все факты ниже — из пунктов теста, сверенных 11.10.2026 (коммит 43fbcdc). Новых норм не добавлял.

```
id: KN-кадры-001
тема: сотрудники
вопрос: Нужна ли медкнижка мастеру в студии?
как_ещё_спрашивают:
  - санкнижка для мастера маникюра
  - если мастер на самозанятости, нужна медкнижка?
  - медосмотр для салона красоты обязателен?
  - работаю одна, мне нужна медкнижка?

короткий_ответ: >
  Для сотрудников студий красоты — да: работодатель обязан отправлять их
  на предварительный и периодические медосмотры и не допускать к работе
  без них. Как правило, медкнижку продлевают раз в год.

от_чего_зависит:
  - есть сотрудники по трудовому договору: обязанность работодателя (ст. 220 ТК РФ)
  - ниша: для студий красоты и общепита указано прямо; для мастерских
    (ремонт обуви, техники, ателье) — не подтверждено, уточнить у юриста
  - работаете в одиночку / мастера на самозанятости: в проверенных пунктах
    теста ответа нет → вопрос юристу (см. «не сверено»)

шаги:
  - Составить список сотрудников, которым по роду работы нужна медкнижка.
  - Направить их в аккредитованный медцентр на медосмотр.
  - Оформить медкнижку. С 1 сентября 2026 новые оформляются только
    в электронном виде; бумажные действуют до конца своего срока.
  - Завести таблицу: у кого и до какого числа действует (обычно 1 год).
    В приложении — внести даты во вкладку «Мои сроки».

частые_ошибки:
  - «Мастер на самозанятости — значит, медкнижка не нужна». Если по факту
    это сотрудник, проверка может переквалифицировать отношения (пункт
    теста о подмене трудовых отношений) — тогда и медкнижка нужна.
  - Ссылаются на приказ №302н — он в этой части заменён приказом №29н.

что_будет_если_нет: >
  Допуск к работе без обязательного медосмотра: ИП и должностные лица
  15 000–25 000 ₽, юрлица 110 000–130 000 ₽ (ч. 3 ст. 5.27.1 КоАП РФ).

первоисточники:
  - ст. 220 ТК РФ
  - приказ Минздрава России от 28.01.2021 №29н, приложение, п. 26
    (коммунальное и бытовое обслуживание населения)
  - письмо Минтруда России от 24.09.2024 №15-2/ООГ-3031
  - ч. 3 ст. 5.27.1 КоАП РФ

не_сверено:
  - Дословный текст п. 26 приказа №29н не открылся — вывод сделан
    по письму Минтруда.
  - Нужна ли медкнижка ИП, который работает один без сотрудников,
    и мастеру на самозанятости, арендующему место, — не проверено.

проверено: 2026-10-11
статус: проверено по первоисточнику (частично, см. «не сверено»)
связано: пункт «Медкнижки сотрудников» в тесте маникюра; пункт о подмене
  трудовых отношений
```

## Что поправить (тебе)

1. Хватает ли полей? Может, не хватает «сколько стоит / сколько времени занимает» — это владельцы спрашивают часто.
2. Формулировки в `как_ещё_спрашивают` — так ли говорят мастера в чате?
3. Пункт «работаю одна — нужна ли медкнижка» — есть ли у тебя свой опыт или ответ проверяющего?
