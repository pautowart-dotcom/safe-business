# Где хранить карточки знаний (А2)

Черновик 13.10.2026. Формат карточки — `format-kartochki.md`.

Не путать с модулем `backend/src/modules/knowledge` — это внутренняя вики студии (статьи пишет сам владелец студии, таблицы `knowledge_sections` / `knowledge_articles`). Наши карточки общие для всех клиентов, пишем их мы.

## Вариант 1. Файлы в репозитории

Один файл = одна карточка: `backend/src/modules/knowledge-cards/cards/<тема>/<id>.js`. Так же, как сейчас лежат пункты теста.

**Плюсы**
- Так уже устроен тест: тот же подход, тот же поиск ИИ, ничего нового учить не надо.
- История бесплатно: git показывает, кто, когда и что поменял в норме. Для юриста и для «Что изменилось в законах» (Д6) это готовая лента.
- Claude и law-compliance-monitor правят и проверяют карточки напрямую, без доступа к боевой базе (у меня там только чтение — так и должно остаться).
- Ошибку видно до выхода: правка → просмотр разницы → коммит.
- Не нужны таблицы, миграции, админка. Ноль новых библиотек (JS-файлы читаются как есть).

**Минусы**
- Любая правка карточки выходит к клиентам только после деплоя — а деплой у тебя через точку доступа с телефона.
- Сам ты поправить карточку без меня можешь только в редакторе, не с телефона.

## Вариант 2. Таблица в базе

**Плюсы**
- Правка сразу видна клиентам, без деплоя.
- Можно править через админку с телефона.

**Минусы**
- Нужна админка для карточек — это отдельная работа на несколько сессий, а ты пока единственный редактор.
- Истории правок нет, пока её не сделаем сами.
- Я не могу ни править, ни проверять карточки без записи в боевую базу — а давать мне её не надо.
- Правка с ошибкой сразу уходит клиентам.

## Рекомендация: файлы сейчас, база — когда появится второй редактор

Так же, как сделан тест: весь код (ИИ, сайт, «Центр действий») берёт карточки только через одну точку — `repository.js`. Если однажды понадобится правка без деплоя (юрист-партнёр, второй редактор), меняется только эта точка, остальное не трогаем.

Одно исключение — то, что рождается у клиентов, сразу в базу:
- вопросы, на которые у ИИ не нашлось карточки (Б5) — список на новые карточки;
- счётчик «какую карточку открывали / спрашивали» — чтобы знать, что дописывать первым.

Это маленькая таблица, без админки, читать её можно через доступ только на чтение.
