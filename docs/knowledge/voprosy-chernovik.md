# Черновик вопросов для карточек (А3)

Пометки: **★** — твои примеры из плана (А5–А7), **●** — по-моему, спрашивают чаще всего (моё предположение, не данные — поправь).

Твоя часть: дописать в конец каждой темы свои реальные случаи («у меня было так…») и вычеркнуть то, что никто не спрашивает.
