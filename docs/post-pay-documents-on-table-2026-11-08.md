# После оплаты: документы «на столе» — 08.11.2026

Мини-спека маленького фикса. Код не трогаем, пока не решим вариант.

Связано: [karta-putanicy-2026-10-26.md](karta-putanicy-2026-10-26.md) (§3 «Обзор — свалка», шаблоны спрятаны; этап «Исправить»).

---

## 1) Проблема

Человек оплатил пакет документов / набор с заключением, зашёл в кабинет — и не видит «за что платил»: шаблоны и анкета лежат под длинным списком шагов (или в середине «Обзора»).

## 2) Цель UX

После оплаты и при следующем входе, пока пакет куплен и документы ещё не собраны: сверху «ваши файлы» (пакет / шаблоны / анкета), без охоты в ленте шагов.

## 3) Варианты

### A — минимум (предпочтительный для S)

Только раскладка и якорь, без нового экрана:

1. **Обработать `?addonPayment=done`** на `/security` (returnUrl уже так ставит `addons.routes.js` для залогиненных; фронт сейчас параметр **не читает**).
2. При `addon.purchased` (и/или флаге из query): открыть этап **«Исправить»** (stage 2) и сразу проскроллить к `#path-templates` / `#document-templates`.
3. **Порядок блоков в stage 2:** `DocumentTemplatesCard` **выше** списка нарушений (сейчас наоборот: ViolationsTab → потом шаблоны; сверху лишь текстовая ссылка «Шаблоны документов ↓» от 27.10 — недостаточно после оплаты).
4. Короткий баннер над карточкой при `purchased` и пустом `generated`: «Оплата прошла — соберите документы по анкете» + кнопка к заполнению / «Пакет на подпись».
5. Опционально (тот же S): после `set-password` с анонимного аудита, если в заказе были документы — редирект не просто на `/security`, а на `/security?addonPayment=done` (или `state`), чтобы первый вход тоже попал «на стол».

Legacy без `securityPath`: в `OverviewTab` поднять `DocumentTemplatesCard` выше свалки (Opening/паспорт/сеть) **только если** `addon.purchased` — иначе не ломать привычный «Обзор» для неоплативших.

### B — отдельный экран

Полноэкран «Ваши документы» после оплаты / deep-link, со списком шаблонов и генерацией; выход в Security. Сильнее ясность, но новый маршрут, навигация, дублирование `DocumentTemplatesCard` / состояния оплаты — это уже не мини-фикс.

**Решение спеки:** делать **A**. B — только если A на живых людях не снимет «где мои файлы».

## 4) Какие файлы трогать

| Путь | Зачем |
|------|--------|
| `frontend/src/pages/Security.jsx` | `SecurityPath` stage 2: порядок блоков; чтение `addonPayment`; баннер; якорь `#path-templates` / `#document-templates`; в legacy — место `DocumentTemplatesCard` в overview при `purchased` |
| `frontend/src/pages/AnonymousAudit.jsx` | Текст DoneStep + редирект после `set-password` (`window.location.href → …/security`), если в оплате были документы |
| `backend/src/platform/addons.routes.js` | Только если нужно уточнить returnUrl / query (сейчас уже `/security?addonPayment=done` для не-гостя) — **менять только при необходимости** |

Точечно, без новых модулей.

## 5) Что НЕ трогать

- Логику **пути до 100 %** (расчёт шагов, `pathStep`, resolve нарушений).
- **Онбординг / FirstSteps** в `HomePath.jsx` и слайды (если не добавляем одну строку «Собрать документы» — это отдельное решение, не в этом фиксе).
- **Monthly check** (`/monthly-check`, этап «Держать»).
- Backend генерации шаблонов, цены, ЮKassa, `document-templates.routes.js` (кроме чтения уже существующего `purchased`).
- Переделку вкладок из карты путаницы (3 вкладки, словарь) — это другая стройка.
- `WatchFeedDashboard` / ленту «Что сделать» — не раздувать; максимум позже одна строка-ссылка, не сейчас обязательна.

## 6) Критерий готово + проверка руками

**Готово, если:** после успешной оплаты пакета (из ЛК или из `/audit` с документами) человек за ≤10 секунд видит блок шаблонов/анкеты без скролла через десятки шагов и понимает, что делать дальше (заполнить → PDF).

Проверка:

1. Компания **без** покупки `document_templates` — этап «Исправить» как сейчас (шаги на месте; шаблоны не обязаны быть первыми, если не paid).
2. Оплата из ЛК → возврат ЮKassa на `/security?addonPayment=done` → сразу виден баннер + `DocumentTemplatesCard` сверху stage 2.
3. Анонимный аудит: план с документами → оплата → пароль → вход → те же «ваши файлы» сверху (не пустой путь «Узнать/шаги»).
4. Уже купленный пакет, повторный вход на `/security` — блок документов всё ещё заметен (не только одноразовый query).
5. Этапы «Держать» / «Быть готовым» и проверка месяца без регрессии по клику.
6. `SECURITY_PATH_UI=false` (legacy dashboard): paid — шаблоны не потеряны в середине свалки.
