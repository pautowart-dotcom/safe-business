# План с 26.10.2026: подписка, которая работает сама

*Записано 25.10.2026 по решению владельца: «занеси в план, начнём строить завтра».*

## Почему

Подписка — самое слабое место: регулярных списаний не было ни разу, даты в «Мои сроки» почти никто не вносит. Подписка сейчас просит человека помнить и вписывать даты, а он пришёл, чтобы помнить не пришлось.

Цель — логичное завершение продукта: **тест нашёл → кабинет ведёт до 100 % → дальше подписка сама держит порядок, без ввода дат.**

## Шаг 1. Подписка без дат — нужно, сначала

- Регулярные проверки по ответам теста ниши, без единой введённой даты: огнетушители — осмотр раз в квартал, медкнижки — раз в квартал (уже есть), журналы — раз в месяц, уголок потребителя, Роскомнадзор и т. п.
- Ядро — «Проверка месяца» (modules/monthly/monthlyCheck.js, запуск для клиентов намечен на 1.11): регулярные пункты брать из ответов теста конкретной ниши, у каждого вопроса — ссылка на нашу инструкцию.
- Перед стройкой — показать владельцу, как это выглядит для одной ниши (маникюр).
- Срок: к 1.11.

## Шаг 2. Путь до 100 % в кабинете — нужно, следом

- Каждое нарушение — шаг: инструкция → документ из пакета → «сделано» (можно приложить фото или файл) → индекс растёт.
- Человек видит «осталось 7 шагов», а не «30 нарушений».
- Части уже есть (инструкции, документы, отметка «устранено») — собрать в один путь.

## Шаг 3. Вид приложения и Telegram — позже

- «Похоже на сайт, а не на приложение», напоминания в Telegram.
- После шагов 1 и 2: вид работает на удержание, когда внутри есть ради чего возвращаться.

## Направление после ноября (стратегия, согласовано 25.10)

Не соревноваться с крупными (Контур, СберБизнес, Консультант) по ширине — брать их силы в версии «один человек + ИИ». Одна ставка: **сила подписки — «к проверке готов: мы следим, напоминаем и готовим бумаги, вы подписываете»**.

1. **Сначала — «делаем за вас» + предупреждение о проверке:**
   - готовые к подаче комплекты (уведомление в Роскомнадзор, уведомление о начале работы — заполнены, осталось подписать), «папка к проверке» одним PDF;
   - по ИНН — плановая проверка в реестре → подписка сама пишет «к вам проверка, вот что подготовить» (данные уже приходят через «Ваш бизнес снаружи»). Минус: видны только плановые.
2. **Потом — каналы:** бухгалтеры на аутсорсе (20–50 ИП у каждого) и сети/франшизы через кабинет «несколько точек». Только когда подписка весомая — иначе партнёрам нечего предлагать.
3. **Фоном, постоянно:**
   - проверенное знание — у каждого пункта «сверено, пункт, дата», монитор законов подсвечивает устаревшее;
   - данные рынка — обезличенные сравнения «у 67 % студий нет…», «вы лучше 70 % в нише» (нужен объём тестов).
